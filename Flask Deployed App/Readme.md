# Flask application

This directory contains the Flask entry point, routes, templates, static files, CSV knowledge files, and Plant Doctor service.

The model is stored one level above this directory at:

```text
Model/plant_disease_model_1_latest.pt
```

Start the application from this directory with:

```powershell
python app.py
```

For the complete installation, MongoDB setup, Docker instructions, and tests, read the repository root `README.md`.
